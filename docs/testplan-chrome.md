# Testplan Chrome (v3.4.0)

Pro Punkt ✓ oder ✗ mit einem Satz, was passiert ist.

## Laden
1. `chrome://extensions` → bei Archiver auf ⟳ klicken. Version muss 3.4.0 zeigen, keine roten Fehler.
2. `chrome://extensions/shortcuts` → bei Archiver steht „Overlay ein- oder ausblenden" mit Alt+Shift+A. Falls leer: dort setzen.

## Sichern
3. Bildseite öffnen (Are.na, Behance, Pinterest). Bild ziehen → Zonen erscheinen unten, sehen aus wie bisher.
4. Bild in eine Zone fallen lassen → Toast „Gespeichert in …", Datei liegt im Ordner.
5. Datei vom Desktop in eine Zone ziehen → wird gespeichert.
6. Bild außerhalb der Zonen loslassen → nichts passiert.

## Overlay (neu gebaut)
7. Alt+Shift+A → Overlay öffnet ohne Zonenleiste, sieht aus wie die Vollansicht, nur halbtransparent.
7b. Auf den Namen einer Zone klicken → nur diese Zone. „‹ Alle Zonen" oder Esc → wieder alle.
7c. Beim Ziehen eines Bildes: Downloads-Zone hat dieselbe gestrichelte Linie, keine Extralinie.
8. Auf github.com testen (strenge Sicherheitsregeln): Overlay sieht genauso aus.
9. Bild anklicken → Lightbox mit Domain-Link. „+" → Finder.
10. Bild in andere Zone ziehen, Mehrfachauswahl mit Shift-Klick und gemeinsam verschieben.
11. Zonen per ⋮⋮ umsortieren, im Overlay und in der Vollansicht.
12. Esc mehrmals: Lightbox → Auswahl → Panel → Overlay schließt.
13. Einstellungen → eigene Kombination ändern → neue Kombination öffnet das Overlay, Alt+Shift+A weiterhin auch.

## Sprache
14. Chrome auf Deutsch: alles deutsch. Optional Chrome auf Englisch stellen → alles englisch.

## Vollansicht und Popup
15. Popup: Zone umbenennen → Overlay und Vollansicht zeigen die Änderung sofort.
16. Vollansicht: Bild aus einem anderen Fenster direkt auf eine Karte ziehen → wird gespeichert.

Was nicht klappt: Screenshot plus ein Satz in den Thread.
